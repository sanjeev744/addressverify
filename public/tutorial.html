Tutorial

Set up AddressVerify without writing code

Most stores finish in about fifteen minutes: install, add two checkout pages, choose rules, save, and test.

Start install
1

Install the app

Open AddressVerify from the Shopify admin or enter your shop domain on this site. Complete OAuth so the app can read orders and write validations.

2

Add the block to Thank You and Order Status

In the checkout editor, open Apps, add AddressVerify to Thank You and Order Status, then save those pages. This covers Shop Pay, Apple Pay, Google Pay, and PayPal.

3

Optional: add it to Checkout

If you want suggestions before the customer pays, add the same block on the Checkout page and turn on in-checkout validation.

4

Choose Lite or Full

Lite is house number, PO Box, and special characters. Full runs the complete rule set, including suggestions.

5

Set post-checkout, holds, and tags

Decide whether corrections apply automatically or need review. Turn on holds for invalid or review addresses. Set the tag text for each error type.

6

Approve usage billing and save

Approve $0.02 per unique Shopify order in Shopify billing, then click Save settings. Nothing is live until you save.

7

Test an address

Use Test Address in the app with a real country and street. Check Validation Logs, then place a test order to confirm Thank You and Order Status.
